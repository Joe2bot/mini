开始实现 Mini Coze V1 的第一个 Vertical Slice。

请严格遵循：
- AGENTS.md
- specs/ 下的全部 Spec
- DESIGN.md

当前 Spec 和 Design 已经确认冻结。除非发现明确的实现阻塞问题，不要修改架构、Spec 或 Design。

====================
本阶段目标
====================

只实现第一个最小可运行闭环：

React
  ↓
Spring Boot
  ↓
Run API
  ↓ HTTP
Python Agent Runtime
  ↓
LLM
  ↓
SSE
  ↓
Spring Boot
  ↓
React

目标是让用户能够在前端输入一句话，创建一个 Agent Run，并看到 LLM 的流式输出，最终 Run 正常结束。

====================
本阶段实现内容
====================

1. 项目基础结构

如果当前项目尚未初始化，请按照 DESIGN.md 创建项目结构。

包括：
- React + TypeScript Frontend
- Spring Boot Backend
- Python Agent Runtime

保持三个部分职责清晰。

2. Agent

实现最基本的 Agent CRUD：

- Create Agent
- Get Agent
- Update Agent
- Delete Agent

Agent 至少支持：

- name
- description
- system_prompt
- model_provider
- model_name
- temperature
- max_tokens

暂时不要实现 Tool、RAG、MCP。

3. Agent Run

实现：

POST /api/agents/{id}/runs

要求：

- 创建 run_id
- 创建 trace_id
- 创建 configuration snapshot
- Run 初始状态为 queued
- 返回 HTTP 202 Accepted
- 不等待整个 LLM 执行完成

Run 状态：

queued
→ running
→ completed

失败：

queued/running
→ failed

4. Spring Boot → Python Runtime

按照 DESIGN.md 定义的 Contract，实现内部 HTTP 调用。

Spring Boot 将 Run 的 configuration snapshot 发送给 Python Runtime。

Python Runtime 不直接访问 PostgreSQL。

5. Python Agent Runtime

实现最小 Agent Loop。

本阶段只支持：

User Input
→ System Prompt
→ LLM
→ Final Answer

暂时不实现：

- Tool Calling
- Tool Registry
- RAG
- MCP
- Workflow
- Multi-Agent

需要保留后续扩展这些能力的清晰接口。

6. LLM Adapter

按照 Design 实现 LLM Adapter。

Provider、Model、API Key 必须通过环境变量配置。

不要把 API Key 写入代码。

需要提供一个适合测试的 Fake/Stub LLM，使测试不依赖真实 LLM API。

7. Streaming / SSE

实现 Runtime → Spring Boot → Frontend 的 SSE。

Frontend 应能够实时收到 LLM 输出。

至少定义清晰的事件类型，例如：

- run.started
- llm.delta
- run.completed
- run.failed

具体 Event Schema 遵循 DESIGN.md。

需要考虑：
- run_id
- trace_id
- event_id
- event type
- payload

8. Trace

本阶段实现最基本 Trace：

Run
└── LLM

至少记录：

- trace_id
- run_id
- agent_id
- status
- start_time
- end_time
- latency
- LLM span
- error（如果失败）

Trace 必须在执行过程中产生。

9. Frontend

实现最小 Agent Test UI：

- Agent 列表
- 创建/编辑 Agent
- 输入 User Message
- 点击 Run
- 显示 Run Status
- 显示 Streaming Output
- 显示最终结果
- 显示基本 Trace / Execution Status

暂时不要实现复杂的 Workflow Builder、Knowledge Base、MCP UI。

====================
本阶段明确不做
====================

不要实现：

- Tool Calling
- Tool Registry
- RAG
- Qdrant
- MCP
- Workflow
- Multi-Agent
- Redis
- MQ
- S3 / MinIO
- OpenTelemetry
- 复杂 Permission
- 高级 Analytics

不要因为“以后可能需要”而提前实现这些功能。

====================
测试要求
====================

至少实现：

Unit Test：
- Agent Service
- Run 状态转换
- LLM Adapter
- Trace Event

Integration Test：
- Spring Boot Run API
- Spring Boot → Runtime
- Runtime → Fake LLM
- SSE Event Flow

E2E Smoke Test：

Create Agent
→ Create Run
→ Runtime 执行
→ Fake/Real LLM
→ SSE
→ Final Answer
→ Run completed
→ Trace 可查询

所有测试优先使用 Fake/Stub LLM，不要求 CI 必须依赖真实 LLM API。
